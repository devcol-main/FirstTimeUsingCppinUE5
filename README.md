# FirstTimeUsingCpp In Unreal Engine 5
From Unreal Engine 5, FirstTimeUsingCpp to control actor, out log on both screen and Output Log.

[필수]: 기초 환경 설정 : 액터 세워두기 / 이동 및 회전 로직 구현 (C++ 함수) / 실시간 정보 로그 출력
1. **기초 환경 설정 : 액터 세워두기**
    - [x]  액터 클래스 생성 및 상속
        - `Actor`를 부모로 하는 새로운 C++ 클래스를 생성합니다.
        - 생성한 C++ 클래스를 부모로 하는 블루프린트 클래스를 상속받아 만듭니다.
    - [x]  외형 설정
        - 블루프린트 에디터에서 `StaticMesh Component`를 추가합니다.
        - 메시를 Cube로 지정하여 화면에 보이게 설정합니다.
            - Cube로 지정도 가능
    - [x]  시작 위치 고정
        - 액터의 게임 시작 시 위치는 좌표 (0, 0, 50)입니다.
2. **이동 및 회전 로직 구현 (C++ 함수)**
    - [x]  Move 함수 만들기
        - 액터를 이동시키는 로직을 함수로 구현합니다.
        - 현재 좌표에서 설정 거리만큼 이동하도록 설계합니다.
    - [x]  Turn 함수 만들기
        - 액터를 회전시키는 로직을 함수로 구현합니다.
        - 설정 각도만큼 회전하도록 설계합니다.
    - [x]  랜덤 반복 실행 (10회)
        - 위 두 함수를 활용해 총 10회 무작위 이동과 회전이 일어나도록 구현합니다.
3. **실시간 정보 로그 출력**
    - [x]  좌표 로그 출력
        - 액터가 이동할 때마다 매번 현재 좌표값을 실시간으로 확인해야 합니다.
        - 게임 실행 화면에 좌표값이 나오도록 구현합니다.
        - 게임 화면에 바로 글자가 나타나는 `AddOnScreenDebugMessage` 함수를 사용하여 로그를 출력합니다.
            - (`UE_LOG` 는 콘솔에 로그가 출력되게 하는 함수입니다!)
    - 실제로 액터가 움직일 필요는 없습니다. 
    지금 단계에서는 **게임 화면에 좌표 로그가 출력되는 정도로만 실습**해보면 충분!
