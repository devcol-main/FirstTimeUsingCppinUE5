# FirstTimeUsingCpp
Unreal Engine 5, FirstTimeUsingCpp to control actor, out log on both screen and Output Log.

[필수]: 기초 환경 설정 : 액터 세워두기 / 이동 및 회전 로직 구현 (C++ 함수) / 실시간 정보 로그 출력
1. **기초 환경 설정 : 액터 세워두기**
    - [x]  액터 클래스 생성 및 상속
        - `Actor`를 부모로 하는 새로운 C++ 클래스를 생성합니다.
        - 생성한 C++ 클래스를 부모로 하는 블루프린트 클래스를 상속받아 만듭니다.
    - [x]  외형 설정
        - 블루프린트 에디터에서 `StaticMesh Component`를 추가합니다.
        - 메시를 Cube로 지정하여 화면에 보이게 설정합니다.
            - Cube로 지정도 가능
    - [x]  시작 위치 고정
        - 액터의 게임 시작 시 위치는 좌표 (0, 0, 50)입니다.
2. **이동 및 회전 로직 구현 (C++ 함수)**
    - [x]  Move 함수 만들기
        - 액터를 이동시키는 로직을 함수로 구현합니다.
        - 현재 좌표에서 설정 거리만큼 이동하도록 설계합니다.
    - [x]  Turn 함수 만들기
        - 액터를 회전시키는 로직을 함수로 구현합니다.
        - 설정 각도만큼 회전하도록 설계합니다.
    - [x]  랜덤 반복 실행 (10회)
        - 위 두 함수를 활용해 총 10회 무작위 이동과 회전이 일어나도록 구현합니다.
3. **실시간 정보 로그 출력**
    - [x]  좌표 로그 출력
        - 액터가 이동할 때마다 매번 현재 좌표값을 실시간으로 확인해야 합니다.
        - 게임 실행 화면에 좌표값이 나오도록 구현합니다.
        - 게임 화면에 바로 글자가 나타나는 `AddOnScreenDebugMessage` 함수를 사용하여 로그를 출력합니다.
            - (`UE_LOG` 는 콘솔에 로그가 출력되게 하는 함수입니다!)
    - 실제로 액터가 움직일 필요는 없습니다. 
    지금 단계에서는 **게임 화면에 좌표 로그가 출력되는 정도로만 실습**해보면 충분!
    실제로 움직이는 게임을 만드는 다음 챕터를 기대해주세요~!

### 도전 구현 기능

---

1. **상태 정보 실시간 출력**
    - [x]  매번 이동할 때마다 현재 좌표와 함께, **현재 몇 번째 이동인지**를 화면에 출력합니다.
2. **50% 확률 이벤트 시스템**
    - [x]  나만의 이벤트 함수 생성
        - 이벤트를 처리하는 별도의 함수(예: `void TriggerEvent()`)를 만들어 로직을 분리합니다.
    - [x]  확률 계산 및 실행
        - 각 이동 단계마다 50% 확률을 계산해서 이벤트를 실행시키는 로직을 구현합니다.
        - 힌트: `FMath::RandRange(0, 1)` 또는 `FMath::FRand()`를 활용해 보세요.
3. **최종 결과 리포트 (10회 이동 종료 후)**
    - [x]  이동 거리 계산 로직
        - 이전 좌표와 현재 좌표 사이의 거리를 계산하여 총 이동 거리를 누적하는 변수를 구현합니다.
        - 언리얼의 `FVector::Dist(A, B)` 함수를 사용하면 두 지점 사이의 거리를 쉽게 구할 수 있습니다.
    - [x]  데이터 요약 리포트 출력
        - 10회의 이동이 모두 끝나면, 다음 두 가지 정보를 마지막으로 화면에 띄웁니다.
            1. 총 이동 거리: 1단계부터 10단계까지 움직인 모든 거리의 합계
            2. 총 이벤트 발생 횟수: 10번 중 실제로 이벤트가 터진 횟수.
